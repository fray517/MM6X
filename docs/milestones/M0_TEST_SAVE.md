# M0 — Test-save policy

Для M0 не используем «боевые» сохранения кампании.

## Правила
- Локализация проверяется в главном меню: сейв не нужен.
- StaticData/Dialog/Maps: отдельный слот `MM6X-M0` или новая
  игра, которую можно бросить.
- Не перезаписывать ценные слоты.
- После каждого proof — restore файлов игры, затем при желании
  удалить тестовый сейв.
- Если патч оставлен на диске, не продолжать кампанию на нём.

## Где лежат сейвы
Точный каталог saves на этой Ubisoft-сборке ещё не инвентаризирован
(HYPOTHESIS: `%USERPROFILE%\AppData` или папка в My Documents).
Не копировать сейвы в git.
