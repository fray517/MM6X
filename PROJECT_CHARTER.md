# Project Charter — MM6X

## Product statement
MM6X воссоздаёт приключение Might & Magic VI средствами Might & Magic X: Legacy.

## Non-negotiable
1. Сюжет MM6 узнаваем и полон.
2. Квестовые цепочки MM6 сохраняются.
3. Ключевые NPC/локации/подземелья сохраняются.
4. MMX остаётся runtime foundation.
5. Разработка идёт маленькими проверяемыми итерациями.
6. Proprietary assets Ubisoft не хранятся в репозитории.

## Допустимая адаптация
- free movement MM6 → grid movement MMX;
- огромные расстояния → сжатые grid-маршруты;
- бой MM6 → бой MMX;
- старый UI → MMX UI;
- dungeon geometry → grid-compatible reinterpretation.

## Fidelity
По умолчанию: faithful content, adapted mechanics.
